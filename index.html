Modern by design

現代の Web に合わせた設計

古いブラウザ分岐を捨て、ES2020 と WebAssembly の上に作り直しました。

⚡

WASM 変換エンジン

Mozc を Emscripten でビルドしたエンジンを Worker で実行。UI をブロックしません。

🔒

完全ローカル

入力・変換・学習はブラウザ内で完結。サーバーへテキストを送りません。

⌨️

モダンなキーバインド

Ctrl+Space で切替、Space で変換、Shift+Space で前候補。標準 IME の作法に合わせました。

📄

ビルド不要

各ページは HTML 一枚。CSS とアプリ JS はインラインで、そのまま配信できます。

📱

レスポンシブ

デスクトップでもタブレットでも。候補ウィンドウは画面内に収まります。

🧩

拡張しやすい

hechima のセッション層と Mozc WASM を分離。UI だけを差し替えられます。
